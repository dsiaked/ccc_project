# CCC 귀가 버스 앱 역할별 이용 안내

이 문서는 CCC 귀가 버스 앱을 처음 이용하는 **일반 사용자**, **캠퍼스 회계 순장님**, **전체 관리자**를 위한 안내문입니다.

전체 업무는 아래 순서로 진행됩니다.

> 사용자 입금 및 버스 신청 → 캠퍼스 회계 순장님 입금 확인 및 본부 송금 → 전체 관리자 배차 확정 → 사용자 버스표 확인 및 탑승

---

## 1. 일반 사용자 안내

### 이 앱에서 하는 일

귀가 버스를 신청하고, 신청 상태와 확정 버스표를 확인합니다. 버스가 확정된 뒤에는 호차, 행선지, 탑승장소 등 탑승 정보를 확인할 수 있습니다.

### 처음 이용할 때

1. 회원가입 후 로그인합니다.
2. `프로필`에서 이름, 연락처, 소속 캠퍼스가 정확한지 확인합니다.
3. 홈 화면의 공지와 신청 마감 일시를 확인합니다.
4. `버스 신청`으로 이동합니다.

정확한 연락처와 소속 정보는 배차 및 긴급 연락에 사용되므로 반드시 본인 정보로 입력해주세요.

### 버스 신청 방법

1. `버스 신청`에서 신청자 정보와 소속을 확인합니다.
2. 안내된 입금 금액과 계좌를 확인하고 먼저 입금합니다.
3. 입금을 완료한 경우에만 `입금했어요`를 선택합니다.
4. 희망 행선지 1지망과 2지망을 선택합니다.
5. 마지막 확인 화면에서 전체 내용을 검토한 뒤 `신청 완료하기`를 누릅니다.
6. `신청 현황`에서 신청이 정상적으로 접수되었는지 확인합니다.

`입금했어요` 선택은 실제 입금 확인 완료를 의미하지 않습니다. 캠퍼스 회계 순장님이 실제 계좌 입금 내역을 확인해야 입금 확인 처리가 완료됩니다.

### 신청 후 확인할 내용

- 신청 마감 전: `신청 현황`에서 신청 정보를 수정하거나 삭제할 수 있습니다.
- 신청 마감 후: 일반 신청과 정보 수정이 제한됩니다.
- 배차 확정 후: `신청 현황` 또는 `확정 버스표`에서 호차, 행선지, 탑승장소를 확인합니다.
- 일반 신청을 하지 못한 경우: 배차 확정 후 좌석이 남으면 `마감 후 잔여 좌석`을 신청할 수 있습니다.

### 탑승 당일

1. 출발 30분 전까지 탑승장소에 도착합니다.
2. `확정 버스표`에서 본인의 호차와 행선지를 다시 확인합니다.
3. 실제 버스에 탑승한 뒤 탑승 관리 간사님이 안내하는 4자리 코드를 입력합니다.
4. 화면에 `탑승 확인`이 표시되었는지 확인합니다.

### 변경·취소가 필요할 때

- 신청 마감 전에는 신청 화면에서 직접 수정하거나 삭제할 수 있습니다.
- 배차 확정 후에는 직접 수정할 수 없으므로 관리자에게 문의해주세요.
- 일반 신청을 취소하면 입금 상태는 미입금으로 변경됩니다.
- 잔여 좌석 신청은 입금 확인 전까지만 직접 취소할 수 있습니다.

### 사용자 최종 체크리스트

- [ ] 이름, 연락처, 소속 캠퍼스를 정확히 입력했다.
- [ ] 안내된 계좌와 금액을 확인하고 입금했다.
- [ ] 희망 행선지 1지망과 2지망을 확인했다.
- [ ] `신청 현황`에서 접수 여부를 확인했다.
- [ ] 배차 확정 후 호차와 탑승장소를 확인했다.
- [ ] 탑승 후 4자리 코드로 체크인했다.

## 2. 캠퍼스 회계 순장님 안내

### 이 역할이 하는 일

담당 캠퍼스의 버스 신청자와 실제 입금 내역을 확인하고, 신청 마감 후 캠퍼스 입금액을 본부 계좌로 송금한 뒤 완료 사실을 보고합니다. 본부 확인이 필요한 내용은 문의 게시판으로 전달합니다.

### 처음 이용할 때

1. 일반 계정으로 로그인합니다.
2. 메뉴에서 `캠퍼스 회계 순장님 페이지`로 이동합니다.
3. 상단에 표시된 담당 캠퍼스가 맞는지 확인합니다.
4. 본부 공지를 확인합니다.
5. 신청자가 입금할 캠퍼스 계좌를 등록합니다.

담당 캠퍼스가 다르거나 페이지가 보이지 않으면 전체 관리자에게 권한과 담당 캠퍼스 확인을 요청해주세요.

### 신청 기간 중: 개인 입금 확인

1. `버스 신청자 목록`에서 신청자 이름과 입금자명을 확인합니다.
2. 캠퍼스 계좌의 실제 입금 내역과 대조합니다.
3. 실제 입금이 확인된 신청자만 `입금 확인`으로 변경합니다.
4. 미입금 필터를 사용해 아직 확인하지 못한 신청자를 점검합니다.
5. 신청자가 추가되거나 신청 내용이 바뀌면 목록과 금액을 다시 확인합니다.

사용자가 신청 과정에서 `입금했어요`를 선택했더라도 반드시 실제 계좌 입금 내역을 확인한 뒤 처리해주세요.

### 신청 마감 후: 본부 송금

1. 신청 마감 여부를 확인합니다.
2. 활성 신청자 전원의 개인 입금 확인이 끝났는지 확인합니다.
3. 화면에 표시된 본부 송금 계좌와 송금할 금액을 확인합니다.
4. 실제 계좌 이체를 완료합니다.
5. 입금자명은 안내된 형식에 맞춰 입력합니다. 예: `캠퍼스명홍길동`
6. 앱에서 `송금 완료 보고하기`를 누릅니다.
7. 본부 입금 확인 상태가 반영되는지 확인합니다.

본부 송금 계좌가 화면에 표시되지 않으면 송금하지 말고 문의 게시판으로 알려주세요.

### 수정 및 추가 송금

- 송금 완료를 보고한 뒤에는 개인 입금 상태를 수정할 수 없습니다.
- 본부 확인 전 수정이 필요하면 `송금 완료 보고 취소` 후 입금 상태를 수정하고 다시 보고합니다.
- 본부 확인 이후 입금 오류나 명단 수정이 필요하면 문의 게시판에 요청을 남깁니다.
- 추가 신청으로 금액이 증가하면 새 신청자의 입금을 먼저 확인하고, 화면에 표시된 증가 금액만 추가 송금합니다.

### 문의 게시판을 사용해야 하는 경우

- 신청 마감 이후 추가 신청 또는 명단 수정이 필요한 경우
- 입금 오류 처리가 필요한 경우
- 본부 송금 계좌가 보이지 않거나 송금 금액이 맞지 않는 경우
- 본부 입금 확인 후 정정이 필요한 경우

문의에는 대상자 이름, 캠퍼스, 요청 내용, 금액과 필요한 처리 기한을 함께 적어주세요.

### 캠퍼스 회계 순장님 최종 체크리스트

- [ ] 담당 캠퍼스와 입금 계좌를 확인했다.
- [ ] 실제 입금 내역을 기준으로 개인 입금을 확인했다.
- [ ] 미입금 신청자가 남아 있는지 확인했다.
- [ ] 신청 마감 후 본부 송금 계좌와 금액을 확인했다.
- [ ] 실제 송금 후에만 송금 완료를 보고했다.
- [ ] 추가 송금 또는 정정 사항을 확인했다.
- [ ] 본부 확인이 필요한 내용을 문의 게시판에 남겼다.

## 3. 전체 관리자 안내

### 이 역할이 하는 일

전체 운영 기준을 설정하고, 신청·입금·배차·잔여 좌석·탑승 업무를 총괄합니다. 캠퍼스 회계 순장님과 탑승 관리 간사님의 권한을 관리하고, 문의 및 예외 상황을 처리합니다.

### 관리자 화면 이용 방법

- 로그인 후 `전체 관리자` 페이지로 이동합니다.
- `운영 대시보드`에서 신청률, 입금률, 배차율과 현재 운영 단계를 확인합니다.
- 왼쪽 메뉴는 단계별 또는 대상별로 볼 수 있습니다.
- 중요한 작업을 마칠 때마다 운영 체크리스트를 갱신합니다.

### 1단계: 운영 준비

1. `운영 설정`에서 조직, 캠퍼스, 행선지, 버스 옵션을 확인합니다.
2. 예상 참여 인원과 신청 마감 일시를 설정합니다.
3. 캠퍼스 회계 순장님 권한과 담당 캠퍼스를 확인합니다.
4. 탑승 관리 간사님 권한과 담당 호차 운영 계획을 준비합니다.
5. 일반 사용자와 캠퍼스 회계 순장님에게 운영 공지를 전달합니다.

### 2단계: 신청 및 소통 관리

1. `가입·신청·입금·배차 현황`에서 조직별 신청률과 입금률을 확인합니다.
2. 누락된 캠퍼스 또는 비정상 신청을 점검합니다.
3. `공지·문의 관리`에서 캠퍼스 공지와 사용자 홈 공지를 등록합니다.
4. 캠퍼스가 남긴 추가 신청, 입금 오류, 명단 수정 요청을 처리합니다.
5. 사용자 정보를 직접 변경해야 할 때는 요청 근거와 처리 결과를 남깁니다.

### 3단계: 배차

1. 신청 현황과 마감 일시를 최종 확인합니다.
2. 신청을 마감합니다.
3. `배차 계산 및 배차안 관리`에서 신청 인원과 희망 행선지를 기준으로 배차안을 생성합니다.
4. 미배차, 중복 배차, 정원 초과, 탑승장소 누락 등 오류를 검토합니다.
5. 필요한 경우 배차 초안을 수정합니다.
6. 최종 검토 후 배차를 확정하고 버스표가 정상 발급되었는지 확인합니다.

배차를 확정하면 새 계산과 배차 초안 편집이 제한됩니다. 변경이 필요하면 확정 배차 화면에서 먼저 확정을 취소한 뒤 수정해주세요.

### 4단계: 입금 및 검토

1. `개인 입금 · 캠퍼스별 송금 관리`에서 개인 미입금과 캠퍼스 송금 상태를 확인합니다.
2. 캠퍼스의 실제 송금 내역을 확인한 뒤 `본부 입금 확인`으로 처리합니다.
3. 별도 확인 대상과 미입금 사용자를 처리합니다.
4. 캠퍼스 문의와 송금 정정 요청을 확인합니다.
5. 최종 입금 예정액과 확인액이 일치하는지 점검합니다.

실제 계좌 내역을 확인하기 전에는 본부 입금 확인으로 처리하지 마세요.

### 5단계: 탑승 및 운행

1. 확정 배차의 잔여 좌석 수를 확인합니다.
2. 잔여 좌석 신청과 입금 상태를 관리합니다.
3. 탑승 관리 간사님에게 담당 호차를 지정합니다.
4. 출발 전 호차별 탑승 현황과 이동 승인 요청을 확인합니다.
5. 현장 추가 탑승, 호차 이동, 미탑승 등 예외 상황을 지원합니다.
6. 모든 호차의 출발 완료와 특이사항 기록을 확인합니다.

### 6단계: 사후 관리

1. 모든 호차의 출발 완료 상태를 최종 확인합니다.
2. 미처리 호차 이동 요청과 캠퍼스 문의가 남아 있지 않은지 확인합니다.
3. 현장 특수상황 기록과 수정 사유를 검토합니다.
4. 관리자 작업 기록에서 주요 변경 내역을 확인합니다.
5. 필요한 경우 AI 운영 보고서를 생성하고 다음 운영자에게 인수인계합니다.

운영 대시보드는 각 단계의 실제 데이터 상태를 기준으로 `완료 조건 충족` 또는 `확인 필요`를 표시합니다. 최종 완료 표시는 전체 관리자가 실제 운영 상황을 확인한 뒤 직접 처리합니다.

### 전체 관리자 작업 원칙

- 사용자 또는 캠퍼스의 요청 없이 입금 상태, 명단, 송금 보고를 임의로 수정하지 않습니다.
- 입금, 배차, 탑승 상태를 변경할 때는 실제 근거를 먼저 확인합니다.
- 확정, 취소, 삭제처럼 영향이 큰 작업은 대상과 결과를 한 번 더 확인합니다.
- 처리한 문의와 예외 상황은 다른 운영자가 이어서 볼 수 있도록 기록을 남깁니다.
- 관리자 작업 기록에서 주요 변경 내역을 주기적으로 확인합니다.

### 전체 관리자 최종 체크리스트

- [ ] 운영 설정, 권한, 공지를 준비했다.
- [ ] 신청률과 입금률을 확인하고 문의를 처리했다.
- [ ] 신청 마감 후 배차안을 검토하고 확정했다.
- [ ] 잔여 좌석 신청과 입금을 처리했다.
- [ ] 캠퍼스 송금과 본부 입금을 실제 내역으로 확인했다.
- [ ] 탑승 관리 간사님 권한과 담당 호차를 지정했다.
- [ ] 출발 완료 및 현장 특이사항을 확인했다.
- [ ] 주요 관리자 작업 기록을 검토했다.

## 공통 문의 작성 예시

문의 제목은 대상과 요청 내용을 한눈에 알 수 있도록 작성해주세요.

> `[캠퍼스명 / 사용자명] 신청 마감 후 행선지 변경 요청`

문의 내용에는 아래 정보를 포함해주세요.

- 요청 대상자 이름과 연락처
- 소속 캠퍼스
- 현재 상태와 원하는 변경 내용
- 입금 또는 송금 관련 금액
- 요청 사유
- 처리가 필요한 기한
